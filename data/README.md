# Data

This directory holds the public dataset used by these experiments. It is **not** redistributed here;
`download.sh` fetches it from Harvard Dataverse.

## Source

Zamiela, C., Tian, W., Guo, S., Bian, L. (2023).
*Thermal-porosity characterization data of additively manufactured Ti–6Al–4V thin-walled
structure via laser engineered net shaping.* **Data in Brief** 51:109722.
DOI: [10.7910/DVN/BWHYEH](https://doi.org/10.7910/DVN/BWHYEH)

Please cite the original dataset paper when using the data. The terms of use are stated on the
Dataverse record.

## Contents

| File | Size | Description |
|---|---|---|
| `cropped_thinwall_CSV_pyrometer.zip` | 52 MB | 1564 CSV frames, each a 200×201 temperature grid (°C) |
| `cropped_thinwall_CSV_pyrometer/Frame_N` | — | unzipped frames, no file extension |
| `thermal-porosity-table.xlsx` | 120 KB | 1564 rows: frame, time, position, melt-pool area, eccentricity, peak temperature, pore label and pore size |
| `cache/thermal.npy` | 250 MB | generated by `experiments/01_build_cache.py` |
| `cache/labels.parquet` | 60 KB | generated by `experiments/01_build_cache.py` |

## Download

```bash
bash data/download.sh
python experiments/01_build_cache.py
```

## Note on file format

Each `Frame_N` has no extension but is a comma-separated file: one header row of column indices,
then 200 data rows. The first column of each data row is a row index and must be dropped to obtain
the 200×201 temperature field.
