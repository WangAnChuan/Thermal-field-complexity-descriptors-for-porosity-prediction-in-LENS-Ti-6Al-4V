## 二、 详细实验执行结果速览

### 🧪 模块 1：物理机理与统计假设检验（Physical Hypotheses Testing）
- [x] **Exp 1.1 熔池核心特征双样本假设检验**：$T_{max}$ 温降 43.1°C ($p = 1.19 \times 10^{-14}$, Cohen's $d = -0.883$)；
- [x] **Exp 1.2 空间冷基板强导热陷阱验证**：前 20 层聚集了 87.3% 的微孔 ($p = 8.27 \times 10^{-17}$, Cohen's $d = -1.023$)；
- [x] **Exp 1.3 标量温度重叠区（1720~1780°C）判定模糊性验证**：证实单点标量测温无法解耦未熔合，必须依赖 2D 空间热场与梯度场。

### 🧪 模块 2 & 模块 3：全领域 SOTA 横向对决与 5 种子严谨检验（70 组全矩阵）
- [x] **Exp 2.1 对标领域经典基线**：`PyroNet-2D (Tian et al. 2020)` (PR-AUC $71.48 \pm 16.69\%$, Paired t-test $p = 0.0161 < 0.05$ (*))；
- [x] **Exp 2.2 对标领域时空 SOTA 架构**：`CNN-BiLSTM (LRCN Temporal Baseline)` (PR-AUC $90.48 \pm 10.56\%$, F1 $0.8711$, MAE $0.0784$ mm, FLOPs 0.68 G)；
- [x] **Exp 2.3 对标通用视觉与顶会 SOTA 架构**：`ResNet-18` ($80.95\%$), `EfficientNet-B0` ($77.67\%$), `ConvNeXt-Tiny` ($57.45\%, p < 0.0001$), `Swin-T` ($46.73\%, p < 0.0001$)；
- [x] **Exp 3.1 跨 5 独立种子全矩阵复现**：Seeds `[42, 100, 200, 300, 400]`，严格盲测，汇报 Mean ± Std；
- [x] **Exp 3.2 配对显著性假设检验**：对所有 13 个竞争及消融模型输出成对 $t$ 检验精确双侧 $p$ 值。

### 🧪 模块 4：全因子细粒度组件消融实验（Ablation Suite）
- [x] **Exp 4.1 物理几何门控消融（w/o Physical Gating）**：剥离导致尺寸反演 MAE 从 0.0774 mm 暴增至 0.2138 mm ($R^2$ 崩溃至 -0.0861)；
- [x] **Exp 4.2 二维双向状态空间扫描消融（w/o Bi-Scan）**：1D 单向扫描 PR-AUC $92.26\%$，双向扫描提供空间各向同性；
- [x] **Exp 4.3 多尺度感受野嵌入消融（Single-Scale vs Multi-Scale Stem）**：单尺度 Stem 导致尺寸反演 MAE 恶化至 0.1721 mm ($R^2 = 0.0696$)，证明多尺度感受野捕获微观梯度不可替代；
- [x] **Exp 4.4 损失函数消融（Standard BCE vs Weighted BCE vs Focal Loss）**：普通 BCE 在极度失衡（21:1）下 PR-AUC 跌至 $81.68\%$（个别种子暴跌至 $47.35\%$），FAR 飙升至 $1.78\%$；Focal Loss 成功将 FAR 压制至 $0.62\%$。

### 🧪 模块 5：3D XCT 微孔隙尺寸连续定量反演与断裂力学分级评估
- [x] **Exp 5.1 连续尺寸反演精度基准**：Thermal-Mamba 达 MAE = 0.0774 mm ($77.4\ \mu\text{m}$, $R^2 = 0.8328$)；树模型达 16.2 $\mu\text{m}$ ($R^2 = 0.9601$)；
- [x] **Exp 5.2 预测一致性对齐散点图（Parity Plot）**：生成 45° 对角完美线散点图 (Fig 5c)；
- [x] **Exp 5.3 断裂力学跨尺寸分级漏检率敏感性分析**：
  - 微观气孔 ($d < 0.30$ mm)：Recall = 100.0%, MAE = 0.0972 mm
  - 中等未熔合 ($0.30 \le d < 0.60$ mm)：Recall = 100.0%, MAE = 0.0597 mm
  - 严重贯通孔洞 ($d \ge 0.60$ mm)：Recall = 94.44%, MAE = 0.1296 mm。

### 🧪 模块 6：硬件推理延迟与边缘部署效率实测
- [x] **Exp 6.1 参数量与 FLOPs 理论计算量**：Thermal-Mamba 仅 0.41 M 参数，0.52 GFLOPs（远低于 ResNet 1.82 G 与 Swin-T 4.50 G）；
- [x] **Exp 6.2 RTX 3090 真实物理延迟测算**：单帧推理 2.28 ms（Batch=1）；
- [x] **Exp 6.3 吞吐帧率与工业闭环标准对比**：实测吞吐量达 438.8 ~ 7405 FPS，大幅领先 30 FPS 在线闭环门槛；
- [x] **Exp 6.4 帕累托最优前沿分析**：建立精度-参数-延迟帕累托边界 (Fig 8b)。

### 🧪 模块 7：典型失效案例物理归因与特征可解释性
- [x] **Exp 7.1 假阳性与假阴性物理边界归因**：15 处误报均发生在激光掉头扫描极端形变边缘，2 处漏报为接近传感器 50 微米光学分辨率极限的微气泡；
- [x] **Exp 7.2 Grad-CAM 空间注意力热力图可视化**：证实网络焦点严格锁定熔池尾部凝固界面未熔合源头 (Fig 11)；
- [x] **Exp 7.3 孔隙物理像素中心坐标三任务标定**：三任务网络在反演尺寸的同时输出质心坐标，平均像素定位误差仅 6.05 像素（相对误差 < 3%）。
